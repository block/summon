## Composition

The signal object is the one chromatic event Technical Contrast allows: a
single large abstract artwork built from the warm-to-cool trio —
`--contrast-signal-warm` (orange), `--contrast-signal-mid` (magenta),
`--contrast-signal-cool` (periwinkle), bound in `--contrast-signal-gradient`.
It is always optional and always subordinate to the claim, proof, and
comparison.

**Used once, contained.** The trio appears as one large optional artwork and
nowhere else — never bleeding into buttons, badges, or category swatches. Never
reduce it to small icons, badges, underlines, category swatches, or CTA fills;
never spread it into a rainbow accent system or many category colors; never
repeat it as small marks. One surface gets at most one signal object.

**When to spend it.** Use the signal object only when it clarifies energy,
capability, or proof on a hero, landing, or proof band. Omit it entirely on
pricing, model, form, or workflow surfaces when the data should carry the
page — contrast planes, table structure, and type carry the language when
decoration is unnecessary. When a surface asks for "visual interest," the first
answer is a plane flip or a hairline structure; the signal object is the second
answer, and small chromatic accents are never the answer.

**Scale and placement.** The object is large-scale — a compositional plane
element, not an accent. On mobile it is cropped, never miniaturized into
repeated badges. It carries no text, no source-brand artwork, and no
proprietary imagery: it is an abstract composition, named and shaped from the
user's prompt per the [no-source-brand rule](anti-goal.source-brand-leakage).

**Bound:** the trio's containment to one large artwork per surface; no signal
color on any control, badge, underline, or swatch; omission on data-led
surfaces; abstract, source-agnostic composition. **Open:** which band hosts it,
gradient angle and form, whether it appears at all.
