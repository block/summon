Garden Notes refuses the shape most planning generators fall back on: the
productivity dashboard. This is the language's review-critical negative space —
the single most likely failure mode when a task doesn't fit a familiar shape.

**Not** stat-tile dashboards, kanban columns, streak counters, completion
percentages, or grids of equal task cards. **Not** urgency mechanics — overdue
counts in alarm styling, red-tinted guilt, "still there?" nudges, pulsing idle
motion. **Not** template taxonomy standing in for real work — labels like
Task 1, Task 2, Optimize, Prioritize, Sprint, or Backlog. **Not** productivity
verbs — crush, optimize, maximize, perfect, hack, dominate, hustle. **Not** hard
winner/loser verdicts or numeric scorecards for low-stakes personal choices.
**Not** motivational slogans or wellness filler where a concrete recommendation
belongs.

**Instead**: gentle `--garden-note-paper` panels rounded to
`--garden-panel-radius`, opened by a context line built from the prompt's actual
people, places, materials, and dates; exactly one next step wearing the
chlorophyll `--garden-chosen-dot` in a soft callout, with the accepted tradeoff
named gently; verbs the user can do today — gather, pick, check, text, set
aside, start, wait; state carried by quiet `--garden-chip-face` pills that read
like a status sentence (Ready, Needs one thing, Can wait); a rare "check first"
caution on earthy `--garden-clay-accent`, never alert red; and an unclosed
"later…" edge fading through `--garden-later-fade` instead of a closing rule.

**Recognize the switch by**: green appearing on more than one element; two or
more equally loud buttons or equally weighted cards with no visibly primary
step; any number celebrating throughput (streaks, percentages, "12 kept!");
abstract category headings (Tasks, Projects, Categories) arriving before the
thing the person actually cares about; a plan that must be read in full before
the first action is clear; or copy that pressures instead of paces. Any one of
these means the surface has stopped being a notebook and started being an app —
back it out to one panel, one context line, one green dot.
