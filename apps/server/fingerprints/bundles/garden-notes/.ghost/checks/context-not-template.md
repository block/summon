Specific context is what makes Garden Notes calming rather than generic. Reject the
generated surface if it replaces the prompt with abstract planning taxonomy:

- labels like Task 1, Task 2, Optimize, Prioritize, Sprint, or Backlog standing in for real work;
- generic advice before the first action instead of a context line using prompt details;
- missing people, places, materials, dates, constraints, uncertainty, or energy when supplied;
- slogans or wellness filler copy that does not tell the user what to do next;
- overdue counts in alarm styling or red-tinted guilt — state phrases forward ("picks up Thursday", "ready when you are"), never behind.

Open each panel with concrete nouns and verbs from the task. Preserve meaningful details
near the plan so the surface proves it is planning this situation.
