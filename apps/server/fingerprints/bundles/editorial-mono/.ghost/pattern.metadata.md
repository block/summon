## Composition

The mono family is the metadata voice of the surface. Folios, issue labels,
timestamps, ranks, criteria labels, and compact captions read as a disciplined
uppercase mono system with measured `--tracking-label`, kept useful rather than
decorative. Controls, inputs, labels, and metadata all route through the mono
family while the serif workhorse carries paragraphs and headings; `strong`
emphasis goes heavy rather than colored.

**Mono metadata system.** Use mono for the small, exact furniture of an editorial
page — the folio in a corner, an issue or section label, a timestamp, a rank, a
criteria label, a compact caption. Route the folio through `--editorial-folio-font`
at `--editorial-folio-size`, with `--editorial-folio-tracking` and
`--editorial-folio-transform` carrying the tracked, uppercase, page-number
discipline that reads as press furniture rather than chrome. Set the
`--editorial-registration-mark` tick beside the folio like a crop mark on a printed
sheet, so the corner reads as a registered page. Keep it uppercase with measured
tracking and short, parallel wording so it scans as a labeling system, not a
paragraph voice.
The copy atoms are exact and reusable across the surface: Verdict, Evidence, Risk,
Caveat, Recommendation, Accepted tradeoff, What changed, What to watch, Rank,
Criteria. State variants the system must express stay legible: selected option,
recommended path, waiting, blocked risk, ready evidence, empty data, error, and
incomplete comparison. Reserve pill radius for compact mono labels and controls
only, never broad panels.

**Marginalia and footnote discipline.** Metadata that annotates rather than
labels — a source citation, a generation timestamp, the measure a figure was
taken on, a caveat too small for a Risk band — is set as marginalia: mono at
`--editorial-folio-size`, placed in the gutter beside the passage it annotates
on wide measures, or as a footnote line under the region's closing hairline on
narrow ones. Tie note to referent with a mono superscript numeral or the
`--editorial-registration-mark` tick, never an icon or tooltip; a printed page
explains itself in its own margins. Marginalia never interrupts the reading
column and never grows into a sidebar — one line per note, ruled off from the
body by `--editorial-hairline-faint`, so the annotation reads as set in the
margin of the same sheet.

**The instrument corner.** A composed page may carry one small instrument
cluster in a corner of the shell — the folio, the set date, the measure or
version, each a tracked mono fragment separated by the registration tick. This
is the press-room convention of printing the sheet's own particulars on the
sheet: exact, self-describing, and inert. It is furniture, not a status bar —
nothing in it updates live, glows, or invites a click.

These labels frame the [masthead / deck / folio shell](pattern.masthead), tag the
[ruled evidence bands](pattern.evidence) with their short uppercase headers, and mark the
[editorial close](pattern.close) with a compact recommendation or rank label.
